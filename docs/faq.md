# HTTP Client FAQ {#http-client-faq}

Short answers for common setup and request questions.

> **Prerequisites:** [HTTP Client Package](README.md)

## Getting Started {#getting-started}

### How do I make one request? {#one-request}

Inject `Switon\HttpClient\HttpClientInterface`, call `get()` or `post()`, then read the response with `json()`.

### When should I use `request()`? {#when-request}

Use `request()` when the endpoint is not JSON or when you need the raw method path. It still throws on non-2xx responses.

### How do I call `head()`? {#head-request}

Use `head()` when you want the same request path as `request()` without JSON parsing.

## Requests {#requests}

### How do I change timeout or TLS behavior? {#change-timeout}

Use `RequestOptions` for `timeout`, `connect_timeout`, `proxy`, `cafile`, and `verify_peer`.

`RequestOptions::of(3)` sets only `timeout`; `connect_timeout` keeps its own default unless you set it explicitly.

### How do I send a file? {#send-file}

Use `LocalFile` for disk files and `MemoryFile` for generated bytes.

### How do I inspect headers? {#inspect-headers}

Use `header()` for one value and `rawHeaders()` when you need the final header block after redirects.

### Can I pass query parameters in the URL? {#url-query}

Yes. Pass `['https://api.example.com/users', 'page' => 2]` and the client appends the query string.

## Troubleshooting {#troubleshooting}

### Why did I get a typed exception? {#typed-exception}

Transport failures, non-2xx statuses, and bad JSON are separated into typed exceptions. Use the exception class to decide whether to retry, fix the response, or fix the request.

`HttpClientStart`, `HttpClientRequesting`, `HttpClientRequested`, `HttpClientSuccess`, `HttpClientError`, and `HttpClientComplete` are the lifecycle events around one request.

### How do I see the current option surface? {#discover-options}

Run `bash bin/console config:options 'Switon\HttpClient\HttpClientInterface'`.
